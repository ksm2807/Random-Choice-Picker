# Random Choice Picker (Pergunte a Estrela)

App Android nativo, feito com **Kotlin** e **Jetpack Compose**, que ajuda a
tomar decisões simples: o usuário digita duas opções e o app "sorteia"
aleatoriamente uma delas.

## Funcionalidades

- Interface construída inteiramente em Jetpack Compose (declarativa, sem XML)
- Validação de campos: o botão só é habilitado quando as duas opções são preenchidas
- Resultado exibido com animação (`AnimatedVisibility`)
- Design simples e responsivo, com scroll vertical para diferentes tamanhos de tela

## Tecnologias

- Kotlin
- Jetpack Compose (Material 3)
- Android Studio

## Como rodar

1. Clone o repositório
2. Abra a pasta no Android Studio
3. Deixe o Gradle sincronizar as dependências
4. Rode em um emulador ou dispositivo físico (`Run > Run 'app'`)
